## Detailed Findings & Proposed Remediations

### 1. Finding 1 — R-02 (Copywriting / Em Dash) [HIGH]
- **File**: `index.html` (line 6)
- **Violation**: R-02 forbids the em dash character (`—`) in any user-facing UI text or title outside of rule documentation carve-outs.
- **Remediation**: Change title to `<title>Blob Tracker : Studio</title>` or `<title>Blob Tracker | Studio</title>`.

### 2. Finding 2 — R-03 (Mobile Responsiveness) [HIGH]
- **File**: `style.css`
- **Violation**: R-03 requires mobile layout to be resilient without horizontal overflow or cramped, broken views. Currently `.app` is strictly `display: flex; height: 100vh;` with a non-collapsing 340px sidebar, causing broken layouts on phones and small tablets.
- **Remediation**: Add a responsive `@media (max-width: 768px)` stylesheet block that stacks the stage and controls vertically, adapts canvas aspect constraints, and ensures all interactive touch targets meet the 44px minimum.

### 3. Finding 3 — R-32 (Keyboard Accessibility & Focus Indicators) [HIGH]
- **File**: `style.css` (lines 158, 283, 305)
- **Violation**: R-32 forbids `outline: none` without providing a visible custom focus indicator. Currently Tab navigation has no clear focus outlines on buttons, sliders, or text inputs.
- **Remediation**: Remove bare `outline: none` and add a universal, high-contrast `:focus-visible` rule (e.g. `outline: 2px solid #111111; outline-offset: 2px;`) across all buttons, inputs, and selects.

### 4. Finding 4 — R-25 (Color Contrast / Visual Perception) [MEDIUM]
- **File**: `style.css` (line 168)
- **Violation**: Range slider track background (`#dddddd`) against panel background (`#ececec`) has very weak boundary definition.
- **Remediation**: Add a subtle border or deepen the track fill to `#cecece` for clear accessibility.

### 5. Finding 5 — R-31 (Explicit Design Rationale & Dials) [LOW]
- **File**: Workspace root
- **Violation**: R-31 / R-37 requires design decisions and liveliness dials to be documented.
- **Remediation**: Add `DESIGN.md` defining the product's aesthetic identity (Technical HUD / Cartographic Workbench), color system rationale, typography choice (SF Pro + Telegraf), and dial configuration:
  - **ENERGY 2** (Balanced technical precision)
  - **RHYTHM 3** (Distinct visual engines: Sensor, Telemetry, Topography, Viewfinder)
  - **MOTION 1** (Static generative canvas with interactive parameter re-rendering)
